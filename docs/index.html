講座の考え方

スポーツ栄養を
土台から積み上げる

スポーツ栄養は、いきなり細かい話から始めても身につきません。

まずは「だいたいこのくらいのカロリーを摂りましょう」といった基本的な内容から、土台となる考え方を整理していきます。

個人スポーツ栄養講座では、この土台をもとに、競技特性やお子さまの状態に合わせて、より具体的な食事の考え方や実践方法を一緒に組み立てていきます。

本人同席の理由

アスリート本人の
同席が必須です

食事を準備するのは保護者でも、実際に食べて競技をするのはアスリート本人です。本人が「なぜ必要なのか」を理解し、自分で考えて選べるようになることを大切にしているため、個人スポーツ栄養講座では本人の同席を必須としています。

現場で大切にしていること

現場で大切だと
感じていること

これまでSAILSでは、大学生の合宿サポートの中で栄養講座を行い、その内容を実際の食事とつなげながら、

「いつ・何を・どのくらい食べるか」

を選手自身に考えて実践してもらう機会を作ってきました。

講座で学んだことを、その日の食事ですぐに試し、身体の感覚やコンディションの変化を振り返る。

さらに、合宿が終わったあともその考え方を続け、次の大会や日々の競技生活に活かしていく。

SAILSでは、こうした「学ぶ → 実践する → 振り返る → 続ける」ところまでを大切にしています。

そのため個人スポーツ栄養講座でも、知識を伝えるだけでなく、

自分の競技や身体に合わせて、実際の食事に落とし込めること

を重視しています。
